# 多年实现补充

这次使用相同500股文件的全部历史，不改变原始文件。训练运行只能通过DataAccess读取F/E分区；全历史导入阶段是离线准备，并不向PPO传递V/T值。2021年是预热历史，实际交易评价从2022年开始。

价量特征的定义与依赖保存在features.py和快照manifest。w日收益率为close/shift(w)-1；波动率为最近w个单日收益率的总体标准差；量比为volume/rolling_mean(volume,w)-1；均价偏离为close/rolling_mean(close,w)-1。零分母产生缺失。它们均不拟合全时间样本参数，横截面标准化仍逐日仅使用固定eligible样本。

每个AST节点递归登记历史依赖，时序算子叠加路径依赖、二元运算取子路径最大值。合法生成掩码还要为未完成叶子和至少一个字段预留空间，避免仅派生字段消融时生成无法终止的前缀。120日上限包含字段依赖；分区预热121日，额外一天供首日开盘使用前日信号。

行情字典在SegmentEvaluator初始化时准备一次；每个表达式的原始值、标准化值和质量结果缓存。排名按分数降序、代码升序，现金/股份执行顺序不改。与归档第一版比较的测试覆盖逐笔成交、订单、现金、持仓、选股和全部指标。gzip保存完整证据；读取时重新核验结果摘要。持久缓存仍按协议、快照、区间和权重隔离，不跨方法或种子混用奖励。

并发只用于独立实验进程，各自初始化和恢复Python/NumPy/PyTorch随机状态；同种子串行和双进程执行的冻结模型身份与T指标完全相同。所有训练完成后统一V选择，再统一T评价。各组全部种子在suite_manifest中预登记；不挑最佳种子，不根据V/T结果延长某一组。

本轮A/B/E是原型对照子集，C/D仅实现并做合成机制验证。预算基于F/E性能测量确定为4×12候选、Q16、V检查点2/4，1000次总逻辑上限；A固定因子组只运行一次搜索。预算不同处透明披露，不能把固定组计算更少解释成算法公平胜出。

源500股是静态历史流动性筛选样本。原数据复权、预处理、公司行动与退市处理尚未正式审计；开盘成交标记只用观测开盘和假设覆盖全天的停牌标记，不再依赖当天收盘或最终成交量。2026年已在早期原型中查看，故T仍物理隔离但统计含义是历史比较。扩大时间跨度没有修复源样本偏差，也没有产生新的未接触留出集。
