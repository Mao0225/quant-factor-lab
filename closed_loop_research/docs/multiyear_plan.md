# 多年研究升级实施计划（2026-09-21）

用户已同意从120日调试版升级为现有近五年数据、扩展因子空间、增大搜索/PPO预算及多种子对照。本轮在同一会话内实施，按测试→实现→验收推进。

**目标：** 用2021-06-18至2026-06-16的500股、601000行数据完成一轮多年研究比较，保存所有正负结果，不把已查看2026年数据冒充未接触留出集。

**架构：** 保留独立内核与原账本语义。添加历史全量导入、因果价量特征、显式历史依赖上限、准备一次复用多次的行情结构和标准化缓存、压缩证据、预登记多种子运行与比较报告。第一版源代码归档在`versions/first_edition/closed_loop_research/`，第一版数据和结果不修改。

## 固定研究选择

- 原始数据全量复制到新的不可变快照。2021年只用于预热；F=2022–2023，E=2024，V=2025，T=2026至数据末。具体交易日由原始数据日历确定；不凭工作日历伪造缺失行情。
- 原始价量加因果派生：1/5/10/20/60日收益率，5/20/60日波动，量比，均价偏离，日内收益、跳空、振幅/收盘位置。只使用当日和过去值，零分母产生缺失，不回填未来值。
- 初始评分为20日收益率、负5日收益率、负20日波动率，权重0.4/0.3/0.3；仍Top50、日频、次日开盘、等权、仅多头。固定成本不因结果改变。
- 窗口1/5/10/20/60，表达式最多15 tokens，活跃因子最多5；显式总lookback≤120个交易日，包含派生字段本身依赖。合法动作掩码限制超长历史并保证至少含一个字段。
- 工程性能：行情只准备一次，标准化值按表达式缓存，排名使用稳定代码次序；每笔账本和全部日净值继续保留并gzip压缩。用原账本逐项对比证明加速不改语义。
- 先测F/E单次评价耗时，再根据测量锁定批次数/完整表达式数/Q。测量只看F/E，模型选择与历史比较结果不用于调整预算。
- 至少A固定因子、B随机生成、E交易奖励PPO，3个预先固定种子7/19/43。其他IC对照接口保留；本轮是否加入以预算登记文件为准，启动后不按结果增删组。
- T仍是训练禁止读取的独立执行区，但统计解释为`previously_observed_historical`；报告、冻结模型和比较汇总都显示这一点。
- 当前静态500股样本使用2021–2024流动性筛选的偏差仍存在；扩大回测时间不能修复原始样本偏差。
