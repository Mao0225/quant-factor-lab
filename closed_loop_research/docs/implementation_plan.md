# 独立研究内核实施计划（2026-09-20）

依据：`research_design/2026-09-20-research-closed-loop-v0.4.md`，继承 v0.1 的时点与账本要求。用户已授权检查歧义、制定计划并实施，直接在新目录推进。当前工作区没有 Git 元数据，不创建或修改旧系统仓库。

**目标：** 可运行、可追溯、可恢复的研究内核，先完成隔离与交易核算，再完成组合搜索和 PPO；研究界面在内核验收后实施，企业端不在范围内。

**架构：** 独立 Python 包。快照准备器离线生成 F/E/V/T 物理分区；训练进程只持有 F/E 数据视图，搜索器只持有 F 的评价函数。批次事务保存评价、PPO 更新、池提交三个阶段的联合状态。CLI 训练与独立选择/测试分开。全部旧目录只读。

**技术：** Python 3.11、NumPy、pandas、PyArrow、PyTorch、pytest；采用小型可核验的 masked PPO 实现，以完整表达式收集轨迹，避免旧 token 回调跨池问题。

## 歧义与明确裁决

| 问题 | 首版执行口径与依据 |
|---|---|
| 是否重做设计审批 | v0.4 是用户指定的设计，实施已获授权；本表补齐工程口径，正式实验参数必须显式登记。 |
| 区间边界 | F/E/V/T 日期为实际净收益日期。区间首日用上一交易日收盘信号从现金建仓，包含首日费用；warm-up 只读过去。末日按收盘估值，不强制平仓，四段相同。 |
| 目标方差、同分 | 总体方差 ddof=0；横截面总体标准差；分数降序、代码升序；仅资格内标准化。 |
| 股数与成本 | 显式交易单位、现金预算、双边费率、最低佣金、买卖滑点；先卖后买；目标每只占开盘交易前净资产的 1/K；不足 K 留现金；现金不足按排名依次成交，不替补。 |
| 可成交与可卖 | 导入契约明确提供开盘可买/可卖标记及其时点来源，不能拿日末涨跌停标记推断开盘。每日仅调仓一次，T+1 下仅昨日已有仓位可卖。 |
| 公司行动 | 原始价格 + 每日每股分红与股数乘数，开盘交易前处理旧持仓；缺失持仓估值直接运行失败。复权未知或未登记事件不得静默假定无事件。首版不支持复杂配股/退市现金结算，数据适配必须先解决。 |
| 股票池与字段 | 显式 eligible、字段来源/单位/时点/核验声明、逐字段 available_at，过晚披露值在当日不可见。固定历史样本须披露存活与抽样偏差；不继承旧 accepted 因子为可信起点。 |
| 覆盖质量 | 分别对 F 和 E 的实际信号日期检查每日有限覆盖、低覆盖日比例、退化比例；组合任一资格样本全活跃因子缺失则该提案无效。初始组合要求完整覆盖。V/T 不参与候选质量门槛。 |
| 表达式空间 | 首版有限前缀语法：已审计字段、固定常数、加减乘除、取负、截面 rank、固定窗口 delay/mean；除零输出缺失，不用 eval。窗口严格正整数，禁止负移位；复杂度计实际语法 token，不含 END/PAD。 |
| 搜索与奖励 | 确定种子多起点/坐标扰动/启停/替换；Q 计 F 目标接口调用（含缓存），实际回测另计。全零等前置约束失败仅记录提案，不消耗 Q；评价接口中的缺失资格失败计一次无效评价。候选首提案必须为本批原组合加零权重。目标反馈改变后续搜索状态。交易增量组候选未被采用时 Δ、训练奖励均为零。 |
| 缓存 | 只在不可变协议、快照、区间、表达式、权重、种子与版本共同命名空间内缓存；记录 cache hit。重复表达式终止零奖励，不额外回测。 |
| 故障 | 语法/质量/无效组合可分类；I/O、快照损坏、非正净值、非有限目标等基础设施/运行故障抛出并保留安全状态，绝不返回质量 -1。 |
| 恢复 | 完整批次评价后、PPO 更新后、池提交后分别原子保存联合 checkpoint；崩溃从最近阶段恢复。PPO 更新和 checkpoint 之间崩溃则从旧参数+同 RNG 确定性重放，不能累计训练两次。单写者文件锁。 |
| 停止 | 固定批次数、完整表达式数、逻辑回测总预算；预算不足下一完整批次最坏需求时停在安全边界。墙钟预算也是批次边界检查，披露最大一个批次超时。负结果全部保存。 |
| V/T | 只允许预登记批次快照进入 V；开发结束后统一选择（等价于不反馈的定点检查），按 V 主目标选取，平局优先早期；已有 F 权重原样冻结。T 仅独立命令、冻结后一次执行，重复调用读取既有结果。 |
| 实验结论 | 合成 smoke 只能证明机制，不能证明收益有效；多种子 A/B/C/D/E 与补充消融分别记录。C/D 的标签为 E 内固定期限的开盘至后续开盘收益，跨 E 末端丢弃；不用于生成字段。 |

## 核验后复用结论

- `research_pipeline/research_system/portfolio.py`：下一日持仓乘 close-to-close 收益、不足 K 放大、冻结后再分配；与设计不一致，不复用执行器。
- `custom_backtester/custom_bt/engine.py`：处理 next_date 成交后用 today 估值；使用 next_panel 的 if_up/if_down、允许替补与小数股；不复用执行器。
- `research_pipeline/research_system/expression_engine.py`：可参考按证券 rolling 的因果语义，但窗口强转整数、宽字段入口与别名歧义不适合锁定语法，不直接导入。
- `single_factor/expression.py`：栈合法性可参考；依赖旧 vendored tree，首版新建有限语法，避免引入旧配置与数据路径。
- `single_factor/evaluator.py` / `runner.py`：奖励是单因子 IC，test 可进入质量筛选；不复用环境或调度。PyTorch 分布与自动微分作为算法基础复用。
- 用户补充授权：优先复制旧 500 股数据做第一版。采用 `legacy_prototype` 明确登记价格口径、可成交、公司行动与固定样本假设，不阻止原型运行。正式审计模式继续保留。
- 实查 `research_data` 行情只有 391 个代码，原 `single_factor/data/selected_500_liquid_processed/panel.parquet` 才有 500 个；选用后者复制 142 日、71,000 行，其中 22 日预热、120 日研究。
