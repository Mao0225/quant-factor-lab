# 研究工作区：怎样看懂一次实验

适用页面：http://127.0.0.1:8767/ 。更新日期：2026-09-21。

打开“研究项目”，进入某个实验。日常阅读依次看“运行与迭代”“回测与选股”“验证报告”，无须识别计算编号或阅读 JSON。

## 1. 运行与迭代：每轮做了什么

- 顶部查看批次进度、候选尝试数、正式组合变化次数和实际 PPO 更新次数。
- 奖励曲线展示每个候选实际收到的训练反馈。奖励不是投资收益；质量失败与负奖励统计可能重叠。
- 每批说明最后是保留原组合、给原有因子重新调权，还是正式采纳新因子。“试算中使用”不代表正式进入下一批组合。
- 展开候选的“查看评价依据与搜索过程”，可以查看质量检查、基准与候选的反馈期分数、本次试算权重及训练期搜索步骤。回测按钮可直接打开对应结果。
- PPO 表展示实际更新和训练损失；更新过参数不等于投资效果得到改善。

## 2. 回测与选股：这个组合表现怎样

先用“我想查看”选择用途，再用“具体结果”选择批次。默认优先打开已运行的最终测试，其次是验证选中的组合或每轮采用组合。

| 用途 | 主要看什么 |
| --- | --- |
| 最终结果与每轮采用组合 | 冻结测试、验证组合及正式采用组合 |
| 候选组合与对照 | 候选方案及其比较对象 |
| 训练期权重搜索细节 | 调权过程中实际计算的中间方案 |
| 全部已有记录 | 所有允许查看、已经完成的回测 |

结果名称包含轮次、用途和阶段，例如“第 3 轮 · 冻结组合 · 最终测试”。同一份缓存被多轮使用时只显示一次；展开“关联用途”可查看其他引用它的轮次和候选。

先核对评价日期和因子数量，再看累计净收益、最大回撤、净值曲线、逐月收益及交易成本。月度收益由已有日净收益复合计算；曲线没有补造市场指数。不同阶段日期不同，不能直接按收益高低评判哪个组合更好。

下方按交易日查看目标与持仓、订单与原因、实际成交、公司行动。默认显示最后一个交易日，也可用上一日、下一日切换。目标入选不一定实际成交，应结合订单原因判断。

## 3. 验证报告：为什么选中这一轮

页面先解释四个数据阶段的日期和用途：训练期寻找权重，反馈期产生奖励并决定保留组合，验证期选模型，最终测试期检验冻结模型。

验证分数对比图会突出已选中的批次，表格解释其他批次未被选择的原因。当前登记规则是验证目标值最高者胜出、同分时取更早批次，冻结后不重新拟合。目标值不是收益率。

最终测试已运行时，展示实际指标并提供“查看最终测试净值与交易明细”。未运行时明确显示尚未运行，不填零值、不自动执行测试。适用范围说明由该实验的数据与执行约束生成。

## 4. 编号和原始证据在哪里

配置页直接展示费用、资金、日期和研究参数；模型页展示来源实验与因子权重。原始协议、标识和 JSON 仍可在“高级原始证据”中展开，供排查和追溯，日常操作不依赖它们。

本次更新只改善现有记录的索引与展示，没有重训实验、改动奖励、改变冻结权重或重算历史结果。
