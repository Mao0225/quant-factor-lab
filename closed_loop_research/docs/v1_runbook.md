# 独立研究与选股系统 v1

入口设计：research_design/2026-09-21-system-design-v1.md。全部新增业务位于 closed_loop_research/app；原有内核和旧系统目录保留。

## 启动

在项目根目录执行：

```powershell
python -m pip install -r closed_loop_research/requirements.txt
python -m closed_loop_research.app --port 8767
```

打开 http://127.0.0.1:8767 。也可以运行 scripts/start_system_v1.ps1。旧研究报告 8766 不受影响。服务仅绑定本机；同一持久目录只能启动一个服务。

## 数据与首次运行

数据中心“导入/更新”读取已登记的原始 daily_with_maindata_v2.csv，并从旧500股面板只取代码名单。顺序扫描源文件，只投影所需列并保存500股；不把全市场441列载入内存。也可使用 scripts/import_v1_data.py，参数见 --help。

导入产物在 workspace/system_v1/datasets。完整字段目录、财务披露审计、隔离原始列、来源SHA256和价量面板分别保存。重复输入不覆盖旧快照。未核验财务不得加入协议；行业/市值/板块及单位未确认字段禁用并显示原因。换手率单位为百分数原值，但当前源文件最后5个交易日全部为0且存在实际成交，疑似占位；当前换手率过滤禁用。已有方案带有该条件时必须显式修改，系统不会忽略条件。上市天数按交易日与上市日的自然日差，目前可用。

当前为原型数据：固定500股选择偏差、价格复权与公司行动、停牌/涨跌停成交近似等限制在协议和质量记录中披露。现金/持仓/费用的计算机制已测试不等于历史收益数据已正式审计。

## 研究到选股

1. 研究项目创建实验，查看完整协议并锁定启动。日期从实际数据日历生成；修改配置须新建实验。
2. 系统执行 F 拟合、E 奖励和 PPO 批次更新；暂停/停止在安全检查点生效。恢复沿用原协议、快照和随机状态。
3. 注册预算结束后自动在 V 选择并生成候选计算包；最终 T 测试单独发起。当前 T 是已观察历史，不能称全新留出。
4. 在模型管理查看证据、填写说明、人工“设为可用”。候选不会自动开放。模型版本冻结计算参数，展示信息可以编辑且留审计。
5. 选股工作台选择确切版本，设置已开放条件与 Top N。先在完整冻结范围评分，再过滤和截取。每次成功自动保存不可变结果；失败不覆盖上次结果。
6. 保存方案只保存配置，下次加载仍锁该版本并使用最新可用数据；修订创建新记录。股票解释展示真实因子贡献；CSV包含日期、版本和条件。

模型数据就绪与开放状态分别展示；数据过期显示实际日期。score不是上涨概率，自定义过滤/N的历史表现不能借用原模型回测。

## 持久对象和验收

workspace/system_v1 下 datasets/experiments/models/plans/results/jobs/comparisons 分别保留数据、协议和检查点、冻结包、方案修订、结果、任务及对照。页面只读取 /api；不提供任意路径文件服务。

```powershell
python -m pytest closed_loop_research/tests -q
```

小预算 A/B/C/E 多种子对照用于机制验收，负结果如实保留。扩大预算或改参数时须新建协议/实验；已展示结果不能再次宣称未观察。

2026-09-21 验收证据和当前数据限制见 `v1_acceptance.md`。初次验收时9个版本均为候选，选股验收在独立目录完成；随后按用户明确授权，在正式目录开放“500股价量组合 · 原型一号”（E组种子7），补齐说明并生成默认Top 50结果，其余8个版本保留候选。进入选股工作台可直接使用；选股记录可查看已生成名单。界面所称最新数据是源文件的2026-06-16，并非当天行情。
