# 独立研究与选股系统 v1 实施计划

依据：2026-09-21 system-design-v1、integrated-design-decisions、raw-data-inventory，及 v0.4 数学协议。视觉使用 assets/2026-09-21-selection-workbench-approved.png。用户已确认范围，本计划直接执行。

## 检查结论与实现歧义的处理

- 文档“未实现”描述早于现有内核。核验复用 closed_loop_research 的表达式、评分、现金账本、F/E/V/T 权限、优化器、PPO 和检查点；不改旧系统，不把旧结果冒充新实验。
- 数据限已有 500 股的代码集合；原始 TSV 流式读取所需价量、证券属性、财务审计字段。保留完整字段目录。未验证财务在隔离区，训练白名单不接纳它们，页面不开放相关过滤。
- 披露日期晚于交易日不能靠简单屏蔽恢复历史修订版本；核验记录明确“不具备可用历史版本”。行情公司行动/复权证据不足时仍属 prototype，不能升级为 audited。
- F/E/V/T 从实际交易日历扣除 warm-up 后顺序分配，并允许启动前配置；日期与全部数值进入不可变协议。历史数据已被观察，T 标为 previously_observed_historical，不能宣称全新留出集。
- 可用、评价完成、当前数据就绪分别记录。系统自动产生候选；人工点击开放/停用，不能因回测结束自动开放。开放动作保存审计。
- 固定模型评分范围为冻结的 500 代码集合；全部打分后过滤再取 N。缺失/不可用过滤直接失败或解释，不能缩小范围再标准化。
- 本地单用户应用；FastAPI/uvicorn 使用已安装环境，浏览器原生模块与 CSS 实现页面，无额外前端构建依赖。文件对象原子落盘并加写锁；训练串行后台执行以避免 torch 全局随机状态污染。历史对象不可覆盖。
- 暂停/停止在完整批次检查点生效；恢复使用同一协议。停止终结任务但不伪造完成的注册实验。T 使用独立明确入口。

## 阶段与验收

1. **数据和交易基础**：原始 500 股流式导入、441 字段目录、日期/重复/缺失/财务未来披露审计、完整日标记、来源指纹、独立快照；复跑账本和隔离测试。
2. **研究调度**：协议模板与校验、项目/实验、锁定启动、批次任务暂停恢复停止、研究轨迹和预算、自动 V 冻结，独立 T 操作；小预算 A/B/C/E 多种子机制对照，不做效能结论。
3. **模型交接**：不可变计算包、可编辑元数据、开放/停用审计、独立评分与研究同输入一致测试、版本和数据要求检查。
4. **选股业务**：先全范围评分再过滤、未知值规则、最新完整日、异步任务与失败保留成功结果、条件数量绑定、不可变方案修订和结果记录、贡献解释及 CSV。
5. **六页界面**：研究项目五页签、模型管理、数据中心；选股工作台、我的方案、选股记录；任务/设置/帮助。实现选定浅色蓝色视觉及真实空/忙/错误/过期状态。
6. **集成验收**：关键业务单元/集成测试、真实 500 股完整小预算流程、独立模型评分一致、API 与浏览器操作验证、保留证据和运行说明。

## 分工与接口

主 agent 负责应用 API、任务调度、集成、验收；数据子任务负责数据层与导入；模型子任务负责计算包/评分/方案结果；界面子任务负责 static 文件。共同使用 app 子包，避免修改已登记内核代码身份。

应用持久目录默认 workspace/system_v1，数据 datasets/<id>/，实验 experiments/<id>/run/，模型 models/，方案 plans/，结果 results/，任务 jobs/。前端只调用 /api，不直接读取文件。API 契约见 v1_api_contract.md。

## 数值模板

继承可验证的 prototype_protocol，24 个因果价量特征、120 日依赖上限、Top 50、初始 return_20/neg(return_5)/neg(volatility_20) 权重 0.4/0.3/0.3。首轮机制验收用小预算（2 批、每批 4 候选、每侧 Q=6、两个随机种子），正式研究预算另建协议，不能覆盖已运行实验。费用、风险、复杂度、奖励尺度、PPO 和缺失规则完整显示在协议编辑器中；启动时 Protocol.validate 与数据要求共同校验。

## 不变的验收原则

财务未通过时点核验不得进入训练；T 不用于奖励或开发指标；真实负奖励保存；不自动开放模型；不可用过滤不能悄悄忽略；自定义条件不继承原模型绩效；数据日期不是系统日期；旧结果和旧系统保持可访问。

## 2026-09-21 实施结果

六个阶段的原型实现与验收已完成，详见 `v1_acceptance.md`。69项Python测试及前端表单回归通过；真实500股 A/B/C/E × 两个种子完成，研究和独立冻结评分一致。浏览器完成研究暂停恢复、回测证据、模型人工开放、条件选股、解释、方案修订、历史及失败保留验证。

数据升级为正式可研究历史仍有外部证据缺口：财务历史版本、公司行动/复权、固定500股选择偏差和部分属性字典。它们没有被当作已解决；未验证字段保持隔离或禁用。本次PPO未改善最终组合，不能据此宣称方法有效。
