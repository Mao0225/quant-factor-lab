# 四级因子动态组合实验设计

## 1. 目标

在现有独立研究系统上实现四个可公平比较的实验：行为 K-Means 基准、简化 MACoE、PACoE、完整融合模型。四级实验共享同一快照、候选因子池、时间切分、信号转股票权重规则和成本模型，只逐级增加模型组件。

## 2. 防泄漏边界

- K-Means、标准化器和代表因子选择仅使用训练期。
- 日度 IC、Rank IC 和截面回归斜率以信号日记录，但只有在 `signal_date + horizon` 后才能进入 PACoE 历史特征。
- 验证期用于选择簇数、窗口、Top-k 和损失权重；测试期不拟合、不调参。
- 因子值、状态、聚类、模型和回测运行必须绑定相同 `snapshot_id`。

## 3. 共享数据集

先流式读取因子分区，生成紧凑的 `daily_factor_performance.parquet`，字段为 `date/factor_id/ic/rank_ic/slope/sample_count/label_available_date/split`。行为矩阵由训练期日度序列和训练期统计摘要组成。K-Means 从 1,264 个因子压缩出 20-50 个代表因子。动态模型只读取代表因子，避免上千因子的注意力矩阵和股票级张量。

## 4. 四级实验

### E1 基准

训练期行为序列标准化后 K-Means；每簇按中心距离、Rank IC 稳定性和覆盖率选择代表因子。代表因子截面标准化后等权合成 Alpha，形成股票多头组合，并按下一交易日执行。

### E2 简化 MACoE

市场输入为过去 40 日市场收益、波动、上涨比例和横截面离散度。PyTorch 市场路由器使用时间注意力摘要与小型专家网络，为候选因子生成日度分数。训练目标是拟合训练期当日可用于监督的因子表现向量。

### E3 PACoE

每个因子使用严格成熟的滚动 9 维绩效向量：IC、Rank IC、斜率三者各自的均值、标准差和 IR。因子注意力与小型专家网络生成绩效分数。任何日期的输入不包含尚未成熟的未来收益标签。

### E4 完整融合

融合 MACoE 与 PACoE logits，学习 `alpha=sigmoid(a)`；训练期使用 Gumbel Top-k，推理期使用确定性 Top-k。损失包括绩效拟合、相邻日期权重 L1 换手惩罚和专家负载平衡。

## 5. 组合与成本回测

每个交易日先对候选因子做截面 winsorize 和 z-score，再按模型权重合成 Alpha。多头组合买入 Alpha 最高的固定数量股票。信号在下一交易日生效；停牌股票不交易，涨跌停约束按可用标志冻结受限方向。成本为换手乘以手续费与滑点之和。输出毛收益、净收益、年化收益、Sharpe、最大回撤、Calmar、胜率、换手和总成本。

## 6. 产物

每级实验保存配置、候选池、模型权重、日度因子权重、股票持仓、交易记录、净值和指标。统一 `experiment_suite.json` 汇总四级结果，并明确每级是否完成训练、验证和测试。

## 7. 验收

- 合成数据测试证明 K-Means 只使用训练日期。
- 合成数据测试证明 PACoE 特征按 horizon 滞后。
- 成本回测测试证明换手增加会降低净收益。
- Gumbel Top-k 训练有梯度，推理恰好保留 k 个因子。
- 小规模真实烟雾实验完成四级链路；全量运行可通过同一 CLI 配置启动。
