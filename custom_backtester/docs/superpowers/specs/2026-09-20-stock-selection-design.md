# 股票筛选

用户已确认：固定因子组合接入独立的股票筛选页面，输出可解释、可复现的候选股票。

流程：组合详情「用于选股」→ 股票筛选 → 选择日期及 Top N → 后台评分 → 名单、贡献及历史下载。

策略快照包含原始表达式、权重、标准化规则、固定股票池代码、来源组合、研究数据截止日期及内容摘要。每次提交保存快照，不重新优化权重。数据仅加载到指定日期，保留全部过去数据满足滚动窗口；日期默认最新可用交易日。禁止使用未来引用表达式。

评分严格复用组合的每日横截面标准化，再加权求和。筛选发生在标准化之后，避免改变股票池评分口径。默认要求全部有效权重因子有值、有效收盘价；停牌过滤仅使用当日已知状态，缺失状态不猜测。并列按股票代码排序。输出所有股票及排除原因、入选名单、逐因子贡献。

历史日期使用后来形成的策略只作为历史评分预览，明确标注非样本外验证；不将其包装为当时可用策略或回测收益。数据日期、研究截止及策略形成日期都展示。最新缓存可能过时，不称「今日推荐」。

结果独立保存到 saved_backtests 同级 stock_selections，每次唯一目录，包含策略、元信息、排名、候选名单、贡献 CSV。不混入回测收益统计。任务中心支持直达名单。

本期不下单、不自动更新数据、不分配仓位、不重训、不提供上涨概率。校验评分一致性、未来数据隔离、缺失排除、快照与历史持久化、界面提交及组合跳转。
